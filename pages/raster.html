Welcome to the official RASTER website

RASTER has been created for hobbyists and radio enthusiasts
interested with receiving Slow Scan Television.

STATION INFORMATION
Location Hungary
Frequency 4.672 MHz
Mode Upper Sideband
Purpose Experimental SSTV.

TRANSMISSION SCHEDULE

RASTER does not follow a set transmission schedule.

You can receive RASTER around this Time & Timezone The most:
1:00 PM - 4:00 AM EST / EDT

(This time window is not guaranteed)

HOW TO RECEIVE RASTER
You do not need a to receive and decode SSTV images.
1. Tune your receiver to 4.672 MHz USB
2. Connect radio audio to your computer (sound card / virtual cable / SDR)
3. Run SSTV software (MMSSTV, QSSTV, RX-SSTV, MultiScan, etc.)
NOTE: Make sure you're in SimTX, argon.simtx.net:1240!
